# 背单词（English-skill）

一个完全跑在本机的英语背单词工具：查词 → 加入学习列表 → 按艾宾浩斯节奏复习 → 打印正反面卡片。
词库来自剑桥官方词汇表 PDF，解析成统一格式的 JSON；所有数据都是项目目录里的文件，不依赖任何云服务。

> 要让 AI 接手这个项目，让它先读根目录的 `AGENTS.md`，那是给 AI 的项目地图（目录职责、类型契约、接口表、改动落点），能省掉一整轮全量读代码。

## 技术栈

- 前端：React 19 + TypeScript + Vite 6（`src/`）
- 后端：Node 24 原生 `node:http` 写的本地小服务（`server/dict-server.mjs`），零依赖、零框架
- 存储：项目目录下的 JSON 文件（`cache/`、`vocab/`）
- 词典：本机 ECDICT（英汉简明字典，开源，约 77 万词条，产物在 `data/`），查不到才走外部接口
- UI 组件全部手写在 `src/ui/`，API 刻意对齐 antd，将来想换成真 antd 基本只改 import

## 快速开始

需要 Node >= 24。

```bash
npm install
npm run dev:all      # 同时起本地服务(3456) + 前端(5173)
```

然后打开 http://localhost:5173 。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 只起前端 |
| `npm run server` | 只起本地服务（`--watch`，改完自动重启） |
| `npm run dev:all` | 两个一起起，日常用这个 |
| `npm run build` | 类型检查 + 打包到 `dist/` |
| `npm run test:server` | 服务端测试，159 项，跑在临时目录且不联网，不会动你的数据 |
| `npm run ecdict:fetch` | 装本地英汉词典：下载 ECDICT + 解压 + 建索引，一次就够 |
| `npm run ecdict:build` | 已经有 `data/ecdict.csv` 时只重建索引 |

查词和学习列表都要本地服务在跑；服务没起时页面顶部会给提示，此时词库浏览仍然可用（词库 JSON 是打包进前端的）。

第一次用建议先跑一次 `npm run ecdict:fetch` 装上本地词典（详见下面「释义从哪来」），之后查词基本不用等外部接口。装完要重启本地服务才生效。

## 五个页面

### 查词（首页）

输入单词，停手 400ms 自动查询，显示音标和中文释义（英文释义只在点「+ 学习」挑这一阶段要背哪几条时出现，页面上不显示例句）。
词下面显示它属于哪些词库的标签，**不属于任何词库就不显示标签**。
词的右上角有个小按钮，点它把词加进学习列表，加的时候可以勾选「这一阶段要背哪几条释义」。
音标旁边的小标签标释义来源：绿色「本地词典」= 本机 ECDICT，蓝色「在线词典」= 外部接口。搜索框下面那行会告诉你本地词典装没装、收了多少词。

### 批量导入

粘贴多行文本，每行一个单词或句子。
输入框上方是词库筛选标签，点一下就只留下属于该词库的行；句子按「句中出现过该词库的词」判断，能容忍 apples → apple 这类常见变形。
右侧选导入到哪个学习列表，也可以现场新建列表。
导入完成后，服务端会在后台排队把音标和释义补上，页面上能看到进度。

### 学习列表

顶部切换列表，右侧新建。默认列表 `default` 不能删。
词条一行一个平铺，带音标和释义；每条都能单独改「这一阶段要背的释义」，也能移除。
要一次清掉一批，点工具条上的「多选」：每行前面出现勾选框（点词本身也能勾），上方有全选、已选条数和「删除选中」。筛选状态下全选只勾筛出来的那些。
「补充释义」会把缺音标 / 缺释义的词重新抓一遍。

### 词库

只显示词库名称、来源文件，以及标签的改名和重置默认值。
标签就是这个词库在别处（查词页、导入页）显示成什么名字，默认是词库 id。

### 英语学习

导航栏右侧那颗会流光的胶囊，角标是今天要复习的词数。四块内容：

- **目标**：选一个词库当目标，用「已经会的词」和词库词条对比给出达成度；背了词库外的词算「目标外的获得」。
- **挑一批新词开始学**：弹窗里勾词 → 新标签页生成正反面 A4 卡片（正面单词，反面音标 + 中文释义，英文释义不上卡片）→ 同时把当前时间记为开始学习时间。
- **复习计划**：月历视图 + 左上角「按天 / 按周」粒度切换。按天点某天看当天要复习的词；按周点任意一天选中整周，面板列出这一周所有到期的词。只有当前这一天 / 这一周能打卡，打卡分「记住了」（进下一轮）、「没记住」（周期从今天重来）、「退出学习」。
- **打印记录**：每导出一批卡片都会自动留一条档（标题、时间、词数、是不是按周印的、还有多少词待复习）。过一段时间——比如一周后——拿着那批卡片回来，展开记录就能整批标「记住了 / 没记住」，不必在月历里一个个点。按周印的卡片默认按周打卡；卡片里的词后来被从学习列表删掉了会自动跳过；删记录只是删档，不动学习进度。只留最近 60 条。

按周模式适合一周只坐下来复习一次的节奏：卡片按整周一批导出（「打印整周卡片」），打卡时会把这一周内排到的多个复习轮次一次过完——比如周一开始学的词，第 1 / 2 / 4 天都落在同一周，按周打一次卡就直接推到下一周的轮次，行里会标「连过 N 轮」。

## 复习节奏（艾宾浩斯）

开始学习后第 **1 / 2 / 4 / 7 / 15 / 30 / 60** 天各复习一次，7 轮走完算「毕业」。
下次复习日期 = 开始那天的 0 点 + 当前轮次对应的天数；到期只按「天」判断，同一天内几点无所谓。
逾期的词不会散落在过去的日期里，全部折叠进「今天」。
按周打卡时同理，逾期的词折叠进「本周」。

## 数据存在哪

全是项目目录下的 JSON 文件，能直接看、直接备份；将来换成云数据库时，只要替换服务端的读写函数。

| 文件 | 内容 |
| --- | --- |
| `cache/dict-cache.json` | 词典缓存：音标、中文、英文释义全集。本地优先，查过的词不再打外部接口 |
| `cache/study-lists.json` | 所有学习列表和词条，含每个词的学习进度（开始时间、轮次、打卡记录）和打标日志（时间、动作、粒度、累计次数；界面不显示，留给后续功能） |
| `cache/vocab-labels.json` | 词库标签的自定义名 |
| `cache/study-goal.json` | 当前学习目标是哪个词库（第一次设置时才创建） |
| `cache/print-batches.json` | 打印记录：每批卡片印了哪些词、什么时候印的、整批标记过几次。只存「列表 id + 词」，每个词的进度读的时候实时从学习列表算 |
| `vocab/*.json` | 词库本身，统一格式，见下 |
| `data/ecdict.csv` | ECDICT 原始数据（约 200MB），只在建索引时读，建完想省空间可以删 |
| `data/ecdict/` | 本地词典索引（`records.tsv` + `index.bin` + `meta.json`，十几 MB），服务端查词直接读它 |

`cache/` 和 `vocab/` 是你的数据，`data/` 是可以随时重建的词典产物，所以 `.gitignore` 里排掉了 `data/`。

环境变量：`DICT_DATA_DIR` 把 `cache/` 换到别处，`DICT_PORT` 换端口（换端口要同步改前端 hook 里写死的地址），
`DICT_ECDICT_DIR` 换本地词典产物目录，`DICT_ECDICT_OFF=1` 这次启动不用本地词典。

## 词库格式与新增词库

统一格式定义在 `vocab/format.md`，一个词库就是一个 JSON 文件：

```json
{
  "id": "a2-key-2020",
  "name": "A2 Key Vocabulary List",
  "level": "A2",
  "source": "Cambridge English (UCLES 2025)",
  "description": "可选",
  "words": [
    { "word": "a few", "pos": ["det", "adj", "pron"], "examples": ["I invited a few of my friends."] }
  ]
}
```

现有词库：`vocab/ket.json`（剑桥 A2 Key，1661 条词条）。

新增一个词库：

1. 把词表整理成上面的格式，存成 `vocab/<id>.json`；`id` 用 kebab-case、全局唯一。
2. 重启前端（`vocab/*.json` 是构建期打包进去的，热更新不一定认新文件）。
3. 需要的话在 `vocab/` 里放一个 `parse_<来源>.py`，方便以后重新解析。

从 PDF 解析的现成例子是 `vocab/parse_a2_key.py`，两步：

```bash
pdftotext -layout 506886-a2-key-2020-vocabulary-list.pdf _pdf_raw.txt
python3 vocab/parse_a2_key.py
```

需要 poppler 的 `pdftotext`（macOS `brew install poppler`）。
注意这个脚本认的是「单词 (词性)」+ 圆点开头例句的版式，**换一份排版不同的 PDF 就得改里面的正则**，它不是通用解析器。

## 释义从哪来

查词优先用本机的 ECDICT（英汉简明字典，开源，约 77 万词条），本地查不到才去请求外部接口。装一次就够：

```bash
npm run ecdict:fetch
```

它做三件事：从 GitHub Releases 下 `ecdict-csv-28.zip`（约 60MB）→ 解压出约 200MB 的 csv 到 `data/ecdict.csv` → 编译成 `data/ecdict/` 里十几 MB 的索引。`data/` 不进 git，换台机器重跑一次就行。**装完要重启本地服务才生效。**

下载不通（连不上 GitHub）时手动装：自己下 `ecdict-csv-28.zip`，把解压出来的 csv 放成 `data/ecdict.csv`，再跑 `npm run ecdict:build` 建索引。也可以换个下载地址：`ECDICT_URL=<地址> npm run ecdict:fetch`。

查一个词的顺序：

1. `cache/dict-cache.json` 里已经查齐的（`status: ok`）直接用；
2. 本机 ECDICT：音标 + 中文 + 英文释义，一次网络请求都不发；
3. 本地还是缺东西，才走外部接口——dictionaryapi.dev 给音标和英文释义全集，mymemory.translated.net 给中文翻译。

外部接口有限流，所以批量补齐仍走后台队列：并发 2、每次间隔 250ms。**本地词典命中的词不占这个限速**，导入几百个常见词几乎瞬间补完。
一条缓存只有音标 / 释义 / 中文都拿到才标成 `ok`，缺一块标 `partial`，下次查会自动重取。
带空格的短语和句子不查 dictionaryapi.dev（查不到），但 ECDICT 收了 `a few` 这类固定短语。

关于例句：**ECDICT 不带例句，应用也不再显示例句**——词卡只有音标 + 中文释义，打印卡片反面同样只印音标 + 中文，缓存里也不再存例句字段。

缓存里的老数据会自动换成 ECDICT：装好词典并重启服务后，凡是来源不是本地词典的历史缓存被查到时（查词、学习列表、导出卡片都算），服务端就地重查一次本地词典并覆盖，这一步不联网。想一次性全换完，给 `POST /api/dict/repair` 发一次带 `force: true` 的请求，它把所有在学的词重跑一遍；只想补缺的那些，在学习列表点「补充释义」就够。

设 `DICT_NO_NETWORK=1` 可以完全断网跑（只吃缓存 + 本地词典），服务端测试就是这么跑的。

## 常见问题

- **页面提示「本地服务未启动」**：跑 `npm run dev:all`，或单独 `npm run server`。
- **查词页提示「还没装本地词典」**：跑一次 `npm run ecdict:fetch`，装完重启本地服务。
- **以前查过的词还是机翻中文**：装好本地词典并重启服务后不用管它，这些词下次被查到会自动换成 ECDICT 的音标和中文；想立刻全换完就给 `POST /api/dict/repair` 发一次带 `force: true` 的请求。
- **`npm run ecdict:fetch` 下载失败**：手动下 `ecdict-csv-28.zip`，把解压出的 csv 放成 `data/ecdict.csv`，再跑 `npm run ecdict:build`；或者换地址 `ECDICT_URL=<镜像地址> npm run ecdict:fetch`。
- **查词一直没有中文**：mymemory 的免费配额用完了，过一会再试。服务端会把「一个汉字都没有」的返回当失败，不会把警告文案写进缓存。
- **点打印卡片没反应**：浏览器拦了新标签页，允许本站弹窗后重试，或者改用「仅标记开始学习」。
- **卡片上没有音标**：那些词的释义还没补齐。去学习列表点「补充释义」，或等导入后的后台队列跑完。
- **打印记录里的词写着「已移除」**：那个词后来被从学习列表删了，整批打卡时会跳过它，同一批的其他词照常标记。
- **卡片开出来了，却提示「打印记录没保存」**：本地服务中途没响应。卡片和学习进度都不受影响，只是这一批没进「打印记录」，之后不能整批打卡。补救办法：在月历里给这些词单独打卡，或者等它们到期时用「今日复习 / 打印整周卡片」再导一次，那次会重新留档。
- **打印怎么对齐正反面**：卡片按 A4 横向排版，每行内部做了左右镜像，纸沿长边翻面后反面正好落在同一张卡上。
